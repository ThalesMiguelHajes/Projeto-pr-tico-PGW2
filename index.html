    Parte 0 · Conceito

    Por que acessibilidade?

    📖 O que é

    Acessibilidade na web = qualquer pessoa consegue usar o site, inclusive pessoas com deficiência.

    É como a rampa na entrada de um prédio: ajuda quem usa cadeira de rodas, mas também quem está com carrinho de bebê ou mala.

    👁️ Pessoas cegas

    Usam um leitor de tela (que fala o conteúdo) e navegam pelo teclado.

    ✋ Deficiência motora

    Nem sempre conseguem usar o mouse. Usam teclado ou acionadores especiais.

    🤟 Pessoas surdas

    Muitas têm a Libras como primeira língua. O português escrito é a segunda.

    🙋 Todo mundo

    Braço engessado, mouse quebrado, ou quem só quer ser mais rápido com o teclado.

    📊 Números e leis

    • 18,6 milhões de brasileiros têm alguma deficiência (IBGE, PNAD Contínua 2022).
    • Lei Brasileira de Inclusão (Lei 13.146/2015, art. 63): sites de empresas e do governo devem ser acessíveis.
    • Lei 10.436/2002: reconhece a Libras como meio legal de comunicação.
    • WCAG (padrão mundial do W3C) e eMAG (modelo do governo brasileiro) dizem como fazer.

    Parte A · Teclado · 1

    Navegar pelo teclado

    📖 O que é

    O foco é como um cursor: mostra qual item vai receber o próximo comando do teclado.

    Tabvai para o próximo item
    Shift+Tabvolta para o anterior
    Enterabre o link / aperta o botão
    Espaçoaperta botão / marca caixa
    ↑↓escolhe dentro de listas e opções
    Escfecha janelas

    WCAG 2.1.1 – Teclado (nível A): tudo que funciona com mouse precisa funcionar com teclado.

    🧪 Experimente

    Aperte Tab para passar pelos botões abaixo e Shift+Tab para voltar.

    Você apertou: Tab 0 vezes · Shift+Tab 0 vezes

    🔧 Como fizemos

    Nenhum código especial! Links, botões e campos (a, button, input, select) já recebem foco sozinhos. O segredo é usar a tag certa.

    <button type="button">Botão 1</button>   <!-- já recebe foco -->
<a href="#teclado">Teclado</a>           <!-- já recebe foco -->

<!-- Um bloco de texto NÃO recebe foco. Para o VLibras traduzir os
     textos desta apresentação, colocamos tabindex="0" neles: -->
<article class="card" tabindex="0" data-libras="..."> ... </article>
    Próximo: Foco visível →

    Parte A · Teclado · 2

    Foco visível

    📖 O que é

    Quem usa mouse vê a setinha. Quem usa teclado precisa ver onde está o foco.

    O navegador mostra uma borda fina, mas muitos sites apagam com outline: none porque acham "feio". Para quem usa teclado, é como esconder a setinha do mouse.

    Aqui usamos uma borda amarela e grossa, fácil de ver.

    WCAG 2.4.7 – Foco visível (nível AA).

    🧪 Experimente
    1. Aperte o botão para desligar o foco visível.
    2. Aperte Tab algumas vezes. Você sabe onde está?
    3. Volte com Shift+Tab e ligue de novo.
    Link A Link B Link C

    🔧 Como fizemos

    :focus-visible só mostra a borda quando a pessoa usa o teclado (ao clicar com mouse ela não aparece).

    /* css/estilo.css */
:focus-visible {
  outline: 4px solid #ffcd07;      /* borda amarela grossa  */
  outline-offset: 3px;             /* afasta a borda do item */
  box-shadow: 0 0 0 7px #1b1b1b;   /* contorno escuro para dar contraste */
}

/* ❌ NUNCA faça isso sem colocar outro estilo no lugar: */
*:focus { outline: none; }

    Skip link: “Pular para o conteúdo”

    📖 O que é

    Imagine ter que passar pelos 14 links do menu desta página toda vez, só para chegar ao conteúdo.

    O skip link é o primeiro link da página. Ele fica escondido, aparece no primeiro Tab e leva direto ao conteúdo principal.

    WCAG 2.4.1 – Ignorar blocos (nível A) · eMAG 1.5

    🧪 Experimente
    1. Aperte o botão abaixo: o foco volta para o começo da página.
    2. Aperte Tab uma vez: o link amarelo aparece no canto de cima.
    3. Aperte Enter: você pula o menu inteiro.
    🔧 Como fizemos 
    <!-- index.html: primeiro elemento dentro do <body> -->
<a href="#conteudo" class="pular-link">Pular para o conteúdo principal</a>
...
<main id="conteudo" tabindex="-1"> ... </main>   <!-- destino do link -->

/* css/estilo.css: fica fora da tela e "desce" quando recebe foco */
.pular-link        { position: absolute; top: -100px; }
.pular-link:focus  { top: 0; }

    O tabindex="-1" no <main> deixa ele receber o foco quando o link é usado (explicado no slide do tabindex).

    Atalhos de teclado

    📖 O que é

    Os sites do governo (gov.br) têm uma barra de acessibilidade no topo com atalhos padronizados pelo eMAG:

    Alt+1conteúdo
    Alt+2menu
    Alt+3busca (aqui: formulário, porque não temos busca)
    Alt+4rodapé

    Fizemos a nossa barra igual: é a faixa azul-escura no topo da página.

    🧪 Experimente
    1. Aperte Alt+2: o foco vai para o menu.
    2. Aperte Alt+4: vai para o rodapé.
    3. Aperte Alt+1: volta para o conteúdo.

    ⚠️ No Linux, o navegador usa Alt+número para trocar de aba. Teste no Windows ou use os links da barra azul.

    Bônus: aqui as setas ← → trocam de slide.

    🔧 Como fizemos 
    // js/scripts.js
const atalhos = { "1": "conteudo", "2": "menu", "3": "formulario", "4": "rodape" };

document.addEventListener("keydown", function (evento) {
  if (evento.altKey && atalhos[evento.key]) {   // Alt + número?
    evento.preventDefault();                       // cancela o padrão do navegador
    irPara(atalhos[evento.key]);                   // move o FOCO (não só a rolagem)
  }
});

    Os links da barra azul (<a href="#menu">) funcionam até sem JavaScript. O atalho é um extra.

    Parte A · Teclado · 5

    A ordem do Tab e o tabindex

    📖 O que é

    O Tab segue a ordem do código HTML, de cima para baixo. Por isso o HTML deve estar na ordem em que se lê a página.

    Valores do atributo tabindex
    ValorO que faz
    0Entra na fila do Tab, na ordem do HTML.
    -1Fora da fila do Tab, mas pode receber foco pelo JavaScript.
    1, 2, 3…Evite! “Fura a fila” e bagunça a navegação.

    Num site real, o Tab deve parar só em itens interativos. Os textos desta apresentação recebem foco só para demonstrar o VLibras.

    🧪 Experimente

    Aperte Tab aqui. Qual caixa recebe foco?

    A
    tabindex="0"
    B
    sem tabindex
    C
    tabindex="-1"

    A: entra no Tab · B: o Tab pula · C: só pelo botão.

    🔧 Como fizemos 
    <div class="caixa" tabindex="0">A</div>
<div class="caixa">B</div>
<div class="caixa" id="caixa-c" tabindex="-1">C</div>

// js/scripts.js – o botão leva o foco até a caixa C
document.getElementById("caixa-c").focus();

    Parte A · Teclado · 6

    Certo x Errado: use a tag certa

    📖 O que é

    Um “botão” feito com <div onclick> parece um botão, mas: não recebe foco, não funciona com Enter e o leitor de tela não avisa que é um botão.

    🧪 Experimente

    Tente chegar nos dois “botões” abaixo usando só o Tab. Depois clique nos dois com o mouse.

    ❌ Errado: <div onclick>

    Enviar (div)

    O Tab pula este item.

    ✅ Certo: <button>

    Recebe foco e funciona com Enter e Espaço.

    🔧 Como fizemos 
    <!-- ❌ precisaria de tabindex="0", role="button" e JavaScript para Enter e Espaço -->
<div class="falso-botao" id="div-botao">Enviar (div)</div>

<!-- ✅ já vem com foco, Enter, Espaço e é anunciado como "botão" -->
<button type="button" id="btn-certo">Enviar (button)</button>

    Formulário pelo teclado

    📖 O que é
    • <label> ligado ao campo: o leitor de tela fala o nome do campo, e clicar no texto também foca o campo.
    • <fieldset> + <legend>: agrupa opções (como os botões de rádio).
    • Nas opções e listas, use as setas. Na caixa de marcar, use Espaço.
    • Se der erro, o foco volta para o campo errado e a mensagem é avisada.
    🧪 Experimente

    Preencha só com o teclado. Tente enviar vazio primeiro.

    Como prefere a resposta?

    🔧 Como fizemos 
    <label for="nome">Nome</label>          <!-- o "for" aponta para o id -->
<input type="text" id="nome">

// js/scripts.js – no envio, se o nome estiver vazio:
msgForm.textContent = "Preencha o nome.";   // role="alert": o leitor de tela fala
nome.focus();                               // o foco volta para o campo com erro

    Parte A · Teclado · 8

    Janelas (modal) e o foco

    📖 O que é

    Quando uma janela abre por cima da página:

    1. O foco entra na janela.
    2. O Tab fica preso dentro dela (senão a pessoa “se perde” atrás da janela).
    3. Esc fecha.
    4. Ao fechar, o foco volta para onde estava.
    🧪 Experimente

    Abra a janela de ajuda, aperte Tab várias vezes (o foco não sai dela) e feche com Esc. Repare que o foco volta para este botão.

    🔧 Como fizemos 
    // js/scripts.js – se está no último item e aperta Tab, volta para o primeiro
tutorial.addEventListener("keydown", function (evento) {
  if (evento.key !== "Tab") return;
  if (evento.shiftKey && document.activeElement === primeiro) {
    evento.preventDefault();  ultimo.focus();
  } else if (!evento.shiftKey && document.activeElement === ultimo) {
    evento.preventDefault();  primeiro.focus();
  }
});

    Parte B · VLibras · 1

    VLibras

    📖 O que é

    Libras é uma língua completa, com gramática própria. Não é “português com gestos”. Por isso, só ter o texto escrito não basta para muitas pessoas surdas.

    O VLibras é uma ferramenta gratuita do Governo Federal, feita com a UFPB, que traduz texto em português para Libras com um avatar 3D (Ícaro, Hosana ou Guga).

    • Existe como widget para sites (o que usamos), extensão de navegador e app de celular.
    • Quando não existe sinal para uma palavra, o avatar faz a datilologia (soletra letra por letra).
    🧪 Experimente

    Dica: escreva seu nome e veja a datilologia.

    🔧 Como fizemos

    Instalar o VLibras num site são só duas linhas, coladas antes do </body>:

    <script src="https://vlibras.gov.br/app/vlibras-plugin.js"></script>
<script> new window.VLibras.Widget('https://vlibras.gov.br/app'); </script>

    Isso cria o botão azul na lateral. O uso normal é: clicar no botão, depois clicar num texto. No próximo slide mostramos como fizemos ele traduzir sozinho com o Tab.

    Parte B · VLibras · 2

    Como ligamos o Tab ao VLibras

    📖 O que é

    Cada vez que um item recebe foco (ou o mouse passa por cima), o JavaScript segue estes 5 passos. O diagrama acende ao vivo: aperte Tab e observe.

    1. 1. Eventofocusin (Tab) ou mousemove (mouse)—
    2. 2. Pega o textodata-libras → aria-label → label → texto—
    3. 3. Espera 600 msSe apertar Tab rápido, só o último vai—
    4. 4. Enviawindow.plugin.translate(texto)—
    5. 5. Avatar sinalizaO VLibras traduz e o avatar faz os sinais—
    🧪 Experimente

    Aperte Tab nestes cartões devagar, depois bem rápido. No modo rápido, o passo 3 “segura” e só o último é traduzido.

    Boa tarde

    🔧 Como fizemos 
    // 1. Evento: alguém recebeu foco pelo teclado
document.addEventListener("focusin", function (evento) {
  agendarTraducao(evento.target);
});

// 2 e 3. Pega o texto e espera 600 ms (cancela se outro item receber foco antes)
function agendarTraducao(elemento) {
  clearTimeout(temporizador);
  temporizador = setTimeout(function () {
    traduzir(textoDoElemento(elemento));
  }, 600);
}

// 4. Manda para o VLibras (essa função é criada quando o avatar carrega)
window.plugin.translate(texto);

    Por que o atributo data-libras? Os atributos data-* guardam informações extras no HTML. Usamos para escrever um texto curto e simples, que o VLibras traduz melhor que o texto completo.

    ⚠️ window.plugin.translate não está na documentação oficial do VLibras. Funciona na versão atual (7.x), mas pode mudar. Se mudar, o VLibras continua funcionando do jeito normal (clicando no texto).

    Próximo: Bônus – voz →

    Bônus

    Bônus: e quem não enxerga?

    📖 O que é

    O VLibras faz sinais, ele não fala. Pessoas cegas usam um leitor de tela, que lê em voz alta o item com foco:

    • NVDA (Windows, gratuito) · Narrador (Windows)
    • VoiceOver (Mac e iPhone) · TalkBack (Android)

    Para mostrar a ideia, simulamos um leitor de tela simples com a Web Speech API do navegador.

    🧪 Experimente

    Ligue a voz (ou marque Voz no topo) e aperte Tab. Cada item é traduzido em Libras e lido em voz alta.

    Precisa ter voz em português instalada no computador (Chrome e Edge normalmente têm).

    🔧 Como fizemos 
    function falar(texto) {
  window.speechSynthesis.cancel();                    // para a fala anterior
  const fala = new SpeechSynthesisUtterance(texto);   // cria a fala
  fala.lang = "pt-BR";                                // em português
  window.speechSynthesis.speak(fala);                 // fala!
}

    Fim

    Resumo

    ✅ Checklist para qualquer site

    1. Use a tag certa (button, a, label).
    2. Nunca esconda o foco: use :focus-visible.
    3. Coloque o link “Pular para o conteúdo”.
    4. HTML na ordem de leitura; nada de tabindex maior que 0.
    5. Todo campo com <label>; no erro, leve o foco ao campo.
    6. Janelas: foco entra, fica preso, Esc fecha, foco volta.
    7. Instale o VLibras: são só 2 linhas.
